# Kubota Poker セットアップ手順

家族がログインなしで使えるポーカー収支アプリです。記録は**あなたのGoogleアカウントのスプレッドシート**に保存されます。

## 1. スプレッドシートを用意する（5分）

1. Googleスプレッドシートで新しいシートを作り、名前を「Kubota Poker」などにする
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っているコードを全部消し、`apps-script/Code.gs` の中身を丸ごと貼り付ける
4. 2行目あたりの `const PASSCODE = 'kubota';` を、家族で決めた合言葉に変える
5. 保存（💾）し、上の関数選択で `setup` を選んで **実行**
   - 「承認が必要です」と出たら、自分のアカウントを選んで許可する
   - 「このアプリは確認されていません」と出たら **詳細 → (安全ではないページ)に移動** を選ぶ（自分で作ったスクリプトなので問題ありません）
6. 右上の **デプロイ → 新しいデプロイ**
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

## 2. アプリにURLを設定する

`config.js` を開き、`apiUrl: ''` の `''` の中に、さきほどのURLを貼り付けて保存します。

```js
window.KUBOTA_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

## 3. アプリを公開する（GitHub Pages・無料）

1. GitHubにログインし、新しいリポジトリを作る（例：`kubota-poker`）
2. **Add file → Upload files** で、このフォルダの中身をすべてアップロード
   （`index.html`、`config.js`、`manifest.webmanifest`、`sw.js`、`icons` フォルダ）
   - `apps-script` フォルダと README はアップロード不要です
3. **Settings → Pages** で Branch を `main`、フォルダを `/ (root)` にして Save
4. 1〜2分後に `https://あなたのID.github.io/kubota-poker/` で開けるようになります

## 4. 家族のスマホに入れる

1. 公開したURLを家族に送る（アプリの「メンバー」タブの **アプリのURLをコピー** でも取れます）
2. iPhoneの **Safari** で開き、**共有ボタン → ホーム画面に追加**
3. Kubotaのチップのアイコンがホーム画面に並びます
4. 初回だけ合言葉を入力すると、その後は聞かれません

## よくある質問

- **合言葉を変えたい**：Code.gs の `PASSCODE` を変えて、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新しいバージョン → デプロイ**。家族は次に開いたとき新しい合言葉を聞かれます。
- **Code.gs を直した**：上と同じく「新しいバージョン」でデプロイし直すと反映されます（URLは変わりません）。
- **アプリの見た目を更新した**：GitHubのファイルを差し替えるだけです。家族側は次に開いたときに更新されます。
- **データのバックアップ**：スプレッドシートそのものがバックアップです。アプリの「CSVで書き出す」も使えます。
- **電波がないとき**：最後に読み込んだ記録は見られます。保存は電波が戻ってから行ってください。
